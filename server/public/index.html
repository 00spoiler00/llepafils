lle·pa·fils

[ʎepəfíls] m. i f. invariable

1
Persona excessivament primmirada, que troba defectes a tot allò que li posen al davant.
2
inform. Validador de català per a text generat per intel·ligència artificial. Combina la normativa de LanguageTool amb regles pròpies contra calcs de l’anglès, clixés i crosses. «Passa-ho pel llepafils, que això no fa sentit té sentit.»

Posa’l a prova

    Tres capes de mala bava

    capa 1 · determinista

    LanguageTool

    Ortografia, gramàtica, barbarismes, apostrofació, concordances. El conjunt de regles de català més complet que existeix, servit en local: cap dada surt cap a tercers.

    capa 2 · determinista

    Regles anti-IA-ismes

    El que cap corrector marca i tot text d’IA porta: «fa sentit», «en línia amb», incisos amb guió llarg, «és important destacar que», clixés d’era digital. Regles pròpies validades amb corpus.

    capa 3 · criteri

    El model

    La skill del plugin fa que la IA corregeixi amb context, vigili els pronoms febles i torni a validar fins que el veredicte és net. Els noms propis i el vocabulari tècnic no es toquen.

    Instal·la’l

    Plugin de Claude Code (recomanat)

    /plugin marketplace add 00spoiler00/llepafils
/plugin install llepafils@llepafils

    Inclou l’MCP i la skill que valida automàticament els lliurables en català.

    Només l’MCP (Claude Code, Cursor, Claude Desktop…)

    claude mcp add --transport http llepafils https://llepafils.latrup.net/mcp

    Exposa l’eina revisa a qualsevol client MCP.

    API REST

    # POST /api/check → { veredicte, errors[], estadistiques }
curl -s https://llepafils.latrup.net/api/check \
  -H 'Content-Type: application/json' \
  -d '{"text": "Això no fa sentit."}'

    Límit de 20.000 caràcters per petició i 60 peticions per minut i IP.
